About this application (1 languages)

[intro] CC Sweep searches files under a selected directory to find matching names, identical files, and matching beginnings or endings of code files. It has three separate searches: Name Review, Full Checksums and Code Edges. Each scan starts only when you press its scan button. Choosing a directory or saving Config does not start a scan. Start in Name Review: choose a directory, set a mask, and press Refresh. Select a file to find related names and preview its code. Use Full Checksums when you need exact duplicate files, or Code Edges when you want to compare the first and last lines of source files. Click any Notes heading to open its corresponding tab. [tab:name-review] Name Review searches for files with related names and provides a code preview. Directory is the folder to search. Browse selects it; Refresh starts the scan. Mask accepts semicolon-separated patterns such as *.py;*.json. Recursive includes subdirectories. Exclude Directories omits folders matching the specified patterns. The upper list contains files matching the mask. Select a file to place its name in Search and find matching files from the last Name Review scan, including files with other extensions. Starts With and Contains choose how to match the text. Ignore Case ignores capital letters; Ignore Extension compares names without their extensions. X clears Search. The lower list contains matching names. Select a file to read its Code Preview. Show Top or Bottom determines which part is displayed, and Lines sets how many lines appear. PNG and JPG images are excluded from code review. Click column headings to sort the shared Treeviews. Delete Selected to Recycle Bin requests confirmation before moving the selected real files. [tab:full-checksums] Full Checksums finds files with identical whole-file contents, regardless of their names. Choose the directory, mask and excluded folders, then press Scan Checksums. Recursive includes subdirectories. Each file is read to calculate its complete SHA-256 checksum; large scans may take some time. Files with the same checksum are exact duplicate candidates. Duplicates Only hides files with no matching checksum in the results. Click a heading to sort. Delete Selected to Recycle Bin confirms before moving files, not just removing them from the list. [tab:code-edges] Code Edges compares the beginning and ending of code files. Select the folder and mask, then set Top Lines and Bottom Lines. Press Scan Code Edges to calculate checksums for those sections. PNG and JPG files are excluded. Display All shows the full scan. Same Top shows files whose beginning matches, Same Bottom shows files whose ending matches, and Same Top and Bottom requires both parts to match. These checksums compare only the selected portions. Use Full Checksums to check entire file contents. The list supports sorting and selected-file recycling after confirmation. [tab:config] Config stores the scan choices and application paths. Default Directory is the folder used when scanning. Name Review Mask, Full Checksum Mask and Code Edge Mask control which files are examined by each search. Excluded Directories and Recursive control directory traversal. Gateway JSON selects the launcher configuration. Save Config writes these settings to cc_Sweep.json beside the application, along with the current preview line count and the Code Edges top and bottom line counts. Saving Config does not scan files. Appearance belongs in UI Choices rather than Config. [tab:log] Log shows status messages from the current session, including scan counts, scan completions and errors. The status line below the notebook shows the latest operation. The scan results remain in their own tabs. [tab:ui-choices] UI Choices uses the shared interface to set the colour theme, display density, window width and window height. Apply + Save applies the choices and stores them in cc_Sweep.json. In embedded mode, the host application may control the appearance and hide this tab. [tab:gateway] Gateway opens the shared launcher for registered applications, files, folders and links. It refreshes when selected. Gateway is different from the scan search controls. The Gateway JSON setting in Config selects the launcher configuration. In embedded mode the host may hide this tab. [tab:about] About shows the application name and version, and explains the main features. CC Sweep scans files without modifying them during searching. Delete Selected to Recycle Bin is a separate action that requires explicit confirmation. Language-specific Notes use files named cpc_sweep.<language-code>.txt beside the application; English is cpc_sweep.en.txt.
